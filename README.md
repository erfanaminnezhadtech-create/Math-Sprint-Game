#🧮 Math Sprint Game
Math Sprint Game is a fast-paced and interactive arithmetic challenge designed to improve mental math skills. In this game, players must quickly decide whether randomly generated math equations are correct or incorrect. The main goal is to enhance calculation speed, focus, and accuracy while providing an enjoyable and educational experience for users of all ages. This project features rapid-fire math questions, an automatic timing system that records sprint completion time, a clean and modern user interface, and a detailed result summary that shows overall performance. The game is built with clean, extendable code to make it suitable for learning, practicing, and customizing. It was developed to strengthen JavaScript fundamentals, DOM manipulation techniques, event handling, timers, and interactive UI design. Math Sprint Game uses HTML5, CSS3, and vanilla JavaScript, and it runs smoothly on any modern browser without requiring external libraries.
